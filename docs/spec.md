# Follow-up Board

Web App สำหรับจัดการรายชื่อผู้ติดต่อ สถานะ และวันติดตาม

## Tech Stack
- Next.js
- TypesScript
- Prisma
- Supabase PostgreSQL
- Better Auth

## Setup Roles
- ใช้ Package เวอร์ชั่น Stable ล่าสุด
- ห้ามใช้ Beta, Canary หรือ Experimental version 
- หากจำเป็นต้องเพิ่ม Package ให้ตรวจสอบความเข้ากันได้กับ Next.js ก่อนติดตั้ง 

## Working Rules
- ทำเฉพาะงานที่ได้รับคำสั่งในแต่ละครั้ง
- ห้ามเพิ่ม Feature, Logic หรือ UI ที่ไม่ได้ระบุ
- ห้ามแก้ไขส่วนที่ไม่เกี่ยวข้องกับงานปัจจุบัน
- รักษา Design และการทำงานเดิมที่มีอยู่
- หากข้อมูลไม่พอหรือจำเป็นต้องขยายขอบเขต ให้ถามก่อนทำ
