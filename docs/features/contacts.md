# Contacts

จัดการรายชื่อผู้ติดต่อสำหรับ Follow-up Board

หน้า /contacts

## UI
- ใช้ Design หน้า Contacts List จาก Stitch: https://stitch.withgoogle.com/projects/9252136041327023795?node-id=0f1bdfa360eb44a4ac0500e573226f5f
- เพิ่มเมนู Contacts ให้ลิงก์ไปที่ `/contacts`

## Actions
- ดูรายการ Contact
- เพิ่ม Contact
- แก้ไข Contact
- ลบ Contact


## Contact Information
- ชื่อ
- บริษัทหรือองค์กร
- อีเมล
- เบอร์โทรศัพท์
- ช่องทางติดต่อ
- สิ่งที่สนใจ
- สถานะ: รายการใหม่, กำลังคุย, รอติดตาม, ปิดงาน
- วันที่ต้อง Follow-up
- หมายเหตุ

## Access
- Contact แต่ละรายการต้องเป็นของ User ที่ล็อกอินอยู่
- ผู้ใช้ดู เพิ่ม แก้ไข และลบได้เฉพาะ Contact ของตัวเอง
